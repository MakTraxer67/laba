# MedTrack

MedTrack — информационная система для учёта назначений врача и фактического приёма лекарств пациентами. Система формирует расписание, сохраняет результаты приёма и рассчитывает статистику соблюдения назначенной схемы.

## Возможности

### Пациент

- регистрация и авторизация;
- просмотр назначений врача;
- просмотр расписания приёма на выбранную дату;
- фиксация результата: «принято», «пропущено» или «перенесено»;
- просмотр истории приёма.

### Врач

- просмотр списка пациентов;
- ведение справочника препаратов;
- создание назначения с дозировкой, периодом и временем приёма;
- просмотр активных назначений;
- завершение назначения;
- просмотр истории и статистики соблюдения схемы пациентом.

### Администратор

- регистрация врачей;
- просмотр пользователей;
- ведение справочника препаратов.

## Как работает программа

1. `main.py` запускает приложение, создаёт базу данных при первом запуске и показывает главное меню.
2. `auth.py` принимает логин и пароль или данные нового пациента.
3. После входа `main.py` открывает меню, соответствующее роли пользователя.
4. `menu.py` получает команды пациента, врача или администратора.
5. Модули из `services` проверяют введённые данные и выполняют бизнес-правила.
6. Модули из `repositories` читают и изменяют данные в SQLite.
7. Объекты из `models` представляют пользователей, препараты, назначения и записи приёма внутри программы.

При первом запуске рядом с проектом появляется файл `medtrack.db`. В нём сохраняются все пользователи, препараты, назначения и результаты приёма. При следующих запусках программа открывает эту же базу, поэтому данные не пропадают.

Когда врач создаёт назначение, сервис проверяет пациента, препарат, дозировку, даты и время. После этого система создаёт назначение и отдельную запись приёма на каждую указанную дату и время. Пациент находит эти записи в расписании и устанавливает результат: «принято», «пропущено» или «перенесено».

## Основные сущности

- `User` — пользователь с ролью пациента, врача или администратора;
- `Medication` — препарат из справочника;
- `Prescription` — назначение врача пациенту;
- `IntakeRecord` — запланированный и фактический приём лекарства.

## Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/MakTraxer67/laba.git
cd laba
```

Если репозиторий уже скачан, откройте терминал в его корневой папке — там, где находятся `README.md`, `requirements.txt` и каталог `src`.

### 2. Создание виртуального окружения

```bash
python -m venv .venv
```

### 3. Активация виртуального окружения

Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Windows Command Prompt:

```cmd
.venv\Scripts\activate.bat
```

Linux и macOS:

```bash
source .venv/bin/activate
```

### 4. Установка зависимостей

```bash
python -m pip install -r requirements.txt
```

Проект использует только стандартную библиотеку Python, поэтому дополнительные пакеты не устанавливаются. Команда оставлена для единого порядка запуска проекта.

## Запуск приложения

Находясь в корневой папке репозитория с активированным виртуальным окружением, выполните:

```bash
python -m src.medtrack.main
```

Приложение запускается как Python-модуль. Это позволяет корректно использовать пакетную структуру проекта и абсолютные импорты.

При первом запуске создаются база `medtrack.db` и администратор:

```text
логин: admin
пароль: admin
```

После первого входа администратор может зарегистрировать врача. Пациент регистрируется самостоятельно из главного меню.

## Запуск в Visual Studio Code

1. Откройте в VS Code корневую папку репозитория.
2. Выберите интерпретатор `.venv` командой `Python: Select Interpreter`.
3. Откройте раздел **Run and Debug**.
4. Выберите конфигурацию `MedTrack` и нажмите `F5`.

Конфигурация находится в `.vscode/launch.json` и запускает модуль `src.medtrack.main`.

### Первый сценарий работы

1. Войдите как `admin` и зарегистрируйте врача.
2. Вернитесь в главное меню и зарегистрируйте пациента.
3. Войдите как врач, добавьте препарат и создайте назначение пациенту.
4. Войдите как пациент, откройте расписание на нужную дату и отметьте результат приёма.
5. Снова войдите как врач и посмотрите историю и процент соблюдения назначения.

## Формат назначения

При создании назначения врач вводит:

- ID пациента и препарата;
- дозировку, например `1 таблетка`;
- время приёма через запятую, например `08:00, 20:00`;
- дату начала и окончания в формате `ГГГГ-ММ-ДД`;
- необязательную инструкцию.

Система проверяет данные и автоматически создаёт расписание на весь период назначения.
